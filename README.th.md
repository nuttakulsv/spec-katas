# spec-katas

[English](README.md) · อยู่ในชุด katas เดียวกับ [staff-katas](https://github.com/nuttakulsv/staff-katas), [em-katas](https://github.com/nuttakulsv/em-katas) และ [review-katas](https://github.com/nuttakulsv/review-katas)

"ทำ checkout ให้เร็วขึ้นหน่อย" "เพิ่มปุ่ม export ให้ที" "ลูกค้าต้องการ SSO" "ทำให้แอปใช้ offline ได้ ทั้งหมดเลย"

งานส่วนใหญ่พังตั้งแต่ก่อนเขียนโค้ดบรรทัดแรก เพราะเราทำตามที่เขาพูด ไม่ใช่ตามที่เขาต้องการจริง ยิ่งตอนนี้ coding agent ทำตามคำขอตรงตัวอักษรเสร็จได้ในบ่ายเดียว การถามให้ถูกตั้งแต่แรกจึงกลายเป็นงานที่มีค่าที่สุดของวิศวกร

spec-katas ให้เราได้ฝึกเรื่องนี้ AI agent จะเล่นเป็นคนสั่งงาน (stakeholder) ที่ขอมาแบบกว้างๆ และมีข้อเท็จจริงที่จะไม่บอกจนกว่าเราจะถามถูกคำถาม เราสัมภาษณ์เขา เขียน spec สั้นๆ แล้วได้ debrief ว่าเจอข้อเท็จจริงข้อไหนบ้าง พลาดข้อไหน และคำถามแบบไหนที่จะเปิดมันออกมาได้ เราตั้งสมมติฐานอะไรไปเองบ้าง และถ้าทำตาม spec ของเรา จะได้อะไรออกมาจริงๆ

## ติดตั้ง

Claude Code

```
/plugin marketplace add nuttakulsv/spec-katas
/plugin install spec-katas@spec-katas
```

Codex, Cursor หรือ agent อื่นที่อ่าน SKILL.md ได้

```
npx skills add nuttakulsv/spec-katas
```

จากนั้นพิมพ์ว่า "เล่น spec kata", "ขอโจทย์ 5" หรือ "ช่วยคิดเรื่องที่หัวหน้าสั่งมานี้หน่อย: ..."

**ไม่มี coding agent?** แปะ [`SKILL.md`](skills/spec-katas/SKILL.md) กับไฟล์โจทย์ลงในแชต AI ตัวไหนก็ได้ แล้วบอกว่า "เริ่มเลย"

## คนสั่งงานทำตัวแบบไหน

- ตอบเฉพาะที่ถาม สั้นๆ แบบคนที่งานยุ่ง ถามละเอียดก็ได้คำตอบละเอียด
- เชื่อในวิธีที่ตัวเองเสนอ และจะเถียงกลับ จนกว่าเราจะเสนอทางที่ดีกว่าไปถึงเป้าหมายของเขา
- ถ้าถามแบบชี้นำ ("แค่ต้องการปุ่ม CSV ใช่ไหมครับ") เขาจะตอบว่า "ใช่ๆ" ทั้งที่อาจไม่ใช่
- ถามไปราว 15 คำถาม เขาจะเริ่มบอกว่าต้องไปแล้ว พอถึง 20 คำถามเขาก็ไป: "สรุปส่งมาทางแชตแล้วกัน"

## ใช้กับทีม

- **น้องใหม่:** เล่นโจทย์ 01 และ 02 ด้วยกัน แล้วเอา spec ที่เขียนมาเทียบกัน
- **ก่อนสั่งงาน agent:** คำถามชุดเดียวกันทำให้เขียน prompt ได้ดีขึ้น spec ที่ได้จาก kata เอาไปใช้สั่ง coding agent ต่อได้เลย
- **สัมภาษณ์งาน:** spec kata 20 นาทีบอกเรื่อง product sense ได้ดีกว่าคำถามว่า "เล่าเรื่องที่เคยเถียงกับ PM ให้ฟังหน่อย"
- **คำขอจริงของเรา:** เล่าคำขอที่ได้รับมา agent จะสร้างสถานการณ์พร้อมข้อเท็จจริงที่น่าจะซ่อนอยู่ให้
